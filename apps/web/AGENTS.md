# Penny v2 browser app

This is the browser client (MAZ-83 onward): React 19, TypeScript, Vite, TanStack Router and TanStack Query, with plain accessible DOM. Don't add React Native, react-native-web, Expo packages or TanStack Start. Read [README.md](README.md) for the stack, layout and conventions, and use the official [TanStack Router](https://tanstack.com/router/latest/docs/framework/react/overview) and [TanStack Query](https://tanstack.com/query/latest/docs/framework/react/overview) docs rather than memory.

- Run every command from `apps/web` with this directory's own npm lockfile (`npm ci`; `npm install <pkg>@<exact>` for new dependencies, pinned exactly). Never add web dependencies to the root `package.json`.
- Routes are files in `src/routes/`; keep everything else outside it. Give each route `staticData: { title }`: the shell renders it as the page's only `<h1>`. Commit the regenerated `src/routeTree.gen.ts`. Validate search params with Zod in `validateSearch` and use `.catch()` so old links still open. Keep every route in `contracts/design-baseline.json` `navigation.routes` opening its page.
- Server state goes through `apiFetch` and per-resource `queryOptions` in `src/api/`. Requests are same-origin `/api/` only. Never compile a server URL, secret or connection string into the bundle, and never read `process.env` in `src/`. Shared calculations and conflict handling stay in the API and shared domain code.
- Take design values from the design kit: run `npm run design:sync` after a kit change and never edit `src/design/tokens.css` by hand. Use Inter and the Ionicons `Icon`. Light and dark follow the system unless pinned in Settings › Appearance. Match `contracts/design-baseline.json` and the `docs/design/penny-ios` web cards, and build screens from the components in `src/design/` (README "Design system and accessibility").
- Build accessibly: use landmarks and headings, label every control, give every action a visible focus state and keyboard access, keep touch targets at least 44px, respect reduced motion, and support 320px through desktop with no horizontal scrolling. Show meaning in text or an icon, never color alone.
- Before finishing, run `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` (which verifies `dist/`) and `npm run test:e2e`, plus the root `npm run lint` and `npm run typecheck` if you touched shared files. Tests fail on any console error or warning. Real .NET/PostgreSQL cross-browser journeys belong to MAZ-95.
