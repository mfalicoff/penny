# ASP.NET Core backend

This is the v2 backend foundation (MAZ-51 onward). Use ASP.NET Core and PostgreSQL 18 with pinned SDK/provider/patch/image versions. Preserve `contracts/openapi.json`, ledger v4, sessions and legacy clients. Follow `docs/migration/postgresql.md`: SQLite is an import/rollback source, not the v2 runtime. Test real HTTP/PostgreSQL with pg_trgm, atomic revisions/projections, isolation, two-worker leases and import/recovery. Run format/analyzers, build, unit/integration and contract checks. Root Expo guidance applies to the legacy app, not .NET here.

Use the standard controller-based startup in `Penny.Backend.Api/Program.cs`. Dependencies point inward: API/Persistence -> Application -> Domain. Follow the repository's `.agents/skills/dotnet-webapi-integration-testing` skill, adapting its examples to the existing `{error:string}` contract. Keep one shared real PostgreSQL fixture; use WebApplicationFactory (Kestrel for transport/lifetime checks), cancellation tokens and per-test isolation. Never introduce SQLite/in-memory stand-ins or silently skip missing containers.

Use `bash apps/backend/dotnet.sh` from the repository root for all .NET commands so caches and temporary files stay in the project. SDK, centralized packages, lockfiles, CSharpier and the PostgreSQL image digest are pinned. Run tool/locked restore, CSharpier check, `format analyzers --verify-no-changes --no-restore`, Release build and `test --solution Penny.Backend.slnx` (Microsoft.Testing.Platform), plus root npm lint/typecheck. See README.md for exact commands.

Migrations run only via the explicit `migrate` command with separate migration credentials and the database advisory lock. Runtime readiness must check connectivity/schema/extension compatibility without changing data. Keep credentials, SQL parameter values, exception details and financial text out of logs. MAZ-52 owns product schema/import; MAZ-121 owns search projections/indexes. Do not expose unfinished product endpoints or replace the legacy deployment in this foundation.
