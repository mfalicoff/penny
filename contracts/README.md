# Shared contracts

`openapi.json` is the OpenAPI 3.1 contract the .NET API implements and the iOS and web apps call. Its paths, envelopes, status codes and messages are what the clients depend on: change them only together with every client. The ledger on the wire is version 4.

- `fixtures/http-journey.json`: sanitized register/ledger/409/shared-projection examples, checked against OpenAPI and the ledger rules by `tests/core/contracts.test.ts` and replayed against the API by the .NET `LedgerTests`.
- `fixtures/parity-cases.json`: cents, personal/shared rounding, anchor dates and three-way merge expectations.
- `fixtures/shared-splits.json`: golden equal/exact/percentage split cases (integer cents, remainder allocation, zero shares, rejected totals) consumed by `tests/core/households-domain.test.ts` and the .NET `HouseholdSplitsTests`.
- `fixtures/settlement.json`: golden monthly balance and suggested-reimbursement cases (partial/complete settlement, ignored months and deleted expenses, zero shares, tie-breaks, largest totals, rejected balances) produced by the TypeScript `calculateMonthlyBalances`/`suggestReimbursements` and consumed by `tests/core/households-domain.test.ts` and the .NET `MonthlySettlementTests`.
- `fixtures/search-cases.json`: local substring and pending cases (the clients' offline search), the shared search normalization (`foldCases`, checked by `tests/core/search-normalization.ts` and the .NET `SearchTextTests`), a server ledger with title/text/typo/filter/sort/pagination cases (`lexicalCases`, `paginationCase`) and English/French/mixed meaning cases (`meaningCases`) run by the .NET real-PostgreSQL `SearchFixtureTests`, receipt text cases (`receiptCases`, MAZ-125: synthetic receipt lines linked to entries, with text, typo and English/French meaning matches) run by `ReceiptTextSearchTests`, plus valid and invalid request examples and a response example. Exotic characters are written as `\u` escapes.
- `fixtures/money.json`, `fixtures/recurrence.json`, `fixtures/merge-conflicts.json` (MAZ-62): golden integer-cent parsing/shares/bounds, anchored recurrence and three-way offline merge cases, **generated** from the reference TypeScript rules (`src/domain`, `src/validation`) by `npm run fixtures:generate` (`scripts/fixtures/generate-golden.ts`); never edit them by hand.
- `fixtures/month-totals.json` (MAZ-136, generated the same way from `src/domain/summary.ts`): Left to spend (recorded) versus Projected around today. Income dated after the person's local date is expected and counts toward Projected only, until its date; `todayCases` turn an instant and an IANA time zone into that date. Scope: income only; future-dated expenses and investments stay recorded (MAZ-139). Consumed by `tests/core/golden-fixtures.test.ts` and the Swift `ReportTests`.
- `fixtures/full-stack-seeds.json` (MAZ-62): deterministic seed scenarios (`empty`, `searchable-household`, `future-income`) run over HTTP by `scripts/test-env/seed.mjs` and by the .NET `FullStackSeedTests`, with search expectations and pending offline edits.
- `fixtures/redesign-states.json` (MAZ-62): the data state, appearances and failure recipe for each of the 61 redesign cards, and recorded/projected totals. Each totals case names its clock, time zone and local `today`; `dana-2026-10` (scenario `future-income`, MAZ-136) has income dated after today in `expected`, checked by TypeScript, Swift and the C# `FullStackSeedTests`.
- `fixtures/manifest.json` (MAZ-62): SHA-256 and consumers of every fixture; regenerate it (`npm run fixtures:generate`) after any fixture edit. TypeScript, C# and Swift verify the hashes.
- `swift/` (MAZ-62): the `PennyContracts` Swift package (strict `Codable` fixture models, loader, manifest hashes) for the native app.
- `design-baseline.json` (MAZ-132): traces for the 61 `docs/design/penny-ios` cards and 42 `design-kit` controls, tokens, navigation and the route map (each web URL and iOS deep link with its destination on iPhone, iPad and web), decisions, behavior issues and source hashes. `visual-comparisons.json` (MAZ-122) records each card's comparison with the iOS and web apps ([visual acceptance](../docs/design/visual-acceptance.md)).

Run `npm run test:core`, `npm run lint`, `npm run typecheck` and `npm run fixtures:check`; `npm run test:fullstack` and `swift test --package-path contracts/swift` cover the full-stack environment and Swift ([test environment](../docs/reference/test-environment.md)). Validate the document with `npm exec --yes --package @redocly/cli@2.76.0 -- redocly lint contracts/openapi.json` (also in CI). The lightweight fixture matcher covers this document's exercised subset; it is not a general JSON Schema validator. Fixtures are consumed through strict typed models in C#, Swift and TypeScript.

No production credentials/data belong here. Synthetic addresses use `.test`; ephemeral generated sessions are never fixture credentials. Change OpenAPI, fixtures, drift tests and [compatibility documentation](../docs/reference/api-reference.md) together. See [architecture](../docs/reference/architecture.md), [PostgreSQL recovery](../docs/reference/postgresql.md) and [search](../docs/reference/search.md).
