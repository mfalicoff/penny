# Icon

Line icons (Ionicons outline, standing in for SF Symbols). The icon inherits text color. Use 22px in rows and toolbars and 24px in tabs. Valid names are in `ICON_NAMES`; common ones are home, list, people, airplane, add, close, checkmark, chevron-back, chevron-forward, calendar, settings, search, options, trash, create, repeat, wallet, card, receipt, cloud-offline, alert-circle, lock-closed and finger-print.

## Example

```tsx
<Icon name="calendar" />
<Icon name="alert-circle" color="var(--pk-danger)" size={18} />
```
