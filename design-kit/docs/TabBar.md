# TabBar

iOS 26 floating glass tab bar: Home, Activity, Shared and Trips, plus a separate copper + (add entry) button. There is no More tab; Recurring, Accounts, Categories and Settings open from Home's settings button. Pass it to `Screen`'s `bottom`. Pushed screens keep the tab bar.

## Example

```tsx
<TabBar active="activity" />
```
