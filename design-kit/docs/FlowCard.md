# FlowCard

Home's "Follow your money" glass card. It shows the `FlowBar`, opens the MoneyFlow screen, and carries an Insights `Pill` in its header. It replaces a separate category row on Home.

## Example

```tsx
<FlowCard spent={1883.35} invested={200} left={1116.65} action={<Pill label="Insights" icon="pie-chart" />} />
```
