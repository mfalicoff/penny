# SectionHeader

Heading above a list or card. The default is a 22pt title with an optional copper action such as "See all". `small` gives the uppercase list header used for day groups and form sections, with an optional meta value such as a day's total.

## Example

```tsx
<SectionHeader title="Recent" action="See all" />
<SectionHeader small title="Friday, Nov 6" meta="−$262.00" />
```
