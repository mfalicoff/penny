# CategoryIcon

Colored tile for a category. Built-in categories: home, groceries, transport, food, shopping, entertainment, health, other; income categories salary, freelance, gifts, income; and investment. Custom categories must use a `--pk-c-*` token. Never use copper, green, indigo, amber or red for a category, because those colors carry meaning.

## Example

```tsx
<CategoryIcon category="groceries" />
<CategoryIcon category="food" size="lg" />
```
