# Button

Filled capsule for actions inside content: sheet footers, alerts and empty states. Use one `primary` (copper) per screen. `destructive` is red text on a red tint. `quiet` is a copper text button. `small` for inline actions such as Retry or Copy.

## Example

```tsx
<Button>Create household</Button>
<Button variant="destructive">Delete for everyone</Button>
<Button small variant="secondary" icon="copy">Copy</Button>
```
