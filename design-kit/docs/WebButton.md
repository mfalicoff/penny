# WebButton

Compact 36px desktop button. Use `primary` (copper) once per page; everything else is white with a hairline. Icon-only buttons are square and need `ariaLabel`. Add `shortcut` to show its key.

## Example

```tsx
<WebButton primary icon="add" shortcut="N">Add entry</WebButton>
<WebButton icon="person-add">Invite</WebButton>
```
